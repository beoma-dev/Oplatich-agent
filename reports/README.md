# Отчёты о состоянии проекта

Здесь живут проверки качества, безопасности и эксплуатации Оплатыча —
не переписка, а документ, к которому возвращаются.

## Правила

- **Один отчёт — один срез во времени.** Старые не удаляем и не
  переписываем задним числом: смысл в том, чтобы видеть движение.
- **Файл называется** `NNN-ГГГГ-ММ-ДД-тема.md`, номера сквозные.
- **Правки внутри отчёта разрешены и ожидаемы**: у каждого риска есть
  статус, и закрывая пункт, меняем статус и дату прямо в файле — так
  видно, что сделано, а что тянется из месяца в месяц.
- **Цифры без команды не считаются.** В конце каждого отчёта — раздел
  «Чем измерено» с точными командами: следующий срез гоняет их же,
  иначе сравнение будет спором, а не сравнением.
